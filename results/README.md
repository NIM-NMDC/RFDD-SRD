# Machine-readable benchmark results

- `internal_cv/` contains the final source/template-group-disjoint five-fold cross-validation results averaged over three training seeds.
- `external_real/` contains the final independent real-world evaluation after unified EXIF orientation normalization.

The aggregate files provide means, standard deviations, and 95% bootstrap confidence intervals. The per-seed files retain the individual repeated-run results. These are data tables only; plotting scripts are deliberately excluded from the public benchmark code.
